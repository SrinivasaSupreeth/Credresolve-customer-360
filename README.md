This project is built around a real-world debt collections problem inspired by CredResolve’s ecosystem.
The goal is to predict the probability of successful recovery for a suggested collection action (such as a field visit, human call, or AI bot call) using borrower behavior and interaction history.

Rather than treating this as a simple ML task, the focus of this project is on building a complete, explainable, and business-oriented pipeline, similar to how decision systems are developed in FinTech companies
